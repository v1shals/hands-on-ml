# hands-on-ml

## Local Python environment

Create a project-local virtual environment and install the project dependencies:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

VS Code is configured to use `.venv` for this workspace. After creating it, select
the `.venv` interpreter if VS Code does not switch automatically.
